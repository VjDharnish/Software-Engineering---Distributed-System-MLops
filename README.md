# Distributed-Systems-MLOps-Roadmap

This repository is a **personal learning roadmap** and project tracker for mastering **Distributed Systems** and **MLOps**. It is designed for **long-term skill development**, combining structured learning, hands-on projects, and reflective journaling.

---

# Minimum Distributed Systems Checklist (THIS is your bar)

If you can comfortably answer **YES** to most of these, you’re good 👇

### Architecture & Theory

-  Can explain CAP with real examples
    
-  Understand strong vs eventual consistency
    
-  Know leader–follower replication
    
-  Understand quorum reads/writes
    
-  Know why distributed transactions are hard
    

### Failure & Reality

-  Know how networks fail
    
-  Understand timeouts & retries
    
-  Know idempotency
    
-  Can reason about partial failure
    

### Practical Systems

-  Have used Kafka / RabbitMQ / PubSub
    
-  Have used Redis / Cassandra / Dynamo-style DB
    
-  Designed APIs with async processing
    
-  Used metrics, logs, tracing
